# Release: Resolver v3.0.1 - History Order, Smarter Duplicates & Dock Fixes

A small follow-up to v3.0 that fixes History's order after restoring favourites, catches more duplicate tags, stops the dock reacting to Android's swipe-up gesture, and keeps the page in place when the keyboard closes.

This update modifies Web UI client assets only, and installs over the air on Resolver v3.0. No new APK is needed.

## Change Log

### 1. History
- **Date Order After Restore:** Restored History Favorites appeared out of order, since a restored image gets a new number but keeps its own date. History is now ordered by when each image was made, which also fixes favourites restored before this update. Older images without a stored time use their date text, or stay beside the image saved before them.

### 2. Prompts
- **Duplicates in Double Brackets:** `((smile)), smile` and `((smile)), (smile)` kept both. Any number of bracket layers, round, square or mixed, now counts as the same tag.
- **Duplicates of Grouped Tags:** `((smile, happy)), smile` kept the second `smile`. Groups spanning commas are still never edited, but a loose copy of one of their tags is now removed, before or after the group. A tag inside a group is no longer removed as a duplicate of an earlier one.

### 3. Dock
- **Android Swipe-Up Gesture:** Swiping up from the bottom edge (home, recent apps) could still switch tabs. A press moving upwards is now dropped at once, a slide starts only on sideways movement, and a tap ending far from where it began doesn't count.
- **No More Jump on Touch:** The highlight no longer jumps to the pressed item as the finger lands; it moves when a slide starts, or to the tapped item as the finger lifts.

### 4. Keyboard
- **Page Stays in Place:** Closing the keyboard no longer drops the page back after it moved up to show the focused box.

### 5. Updates
- **Older App Check:** If this update reaches an app older than v3.0, Resolver now asks to install the new v3.0 APK instead of running without its native parts.

---

## Installation

On **Resolver v3.0**: open the app and tap **INSTALL UPDATE** when asked (or **Config → System Settings → UPDATE CHECK**). On an older version: install the **v3.0 APK** from the releases page first. Your images and settings stay.
