# Release: Resolver v3.1 - Security Update

A security release that moves Resolver's Android layer to a patched version of Capacitor, the framework the app is built on. It also includes everything from v3.0.1.

This update modifies native-level code, requiring a manual installation build. Install the new APK over your current app. Your images and settings stay.

---

## Change Log

### 1. Security
- **Capacitor 6.2.3:** Capacitor's Android layer goes from 6.0 to 6.2.3. Versions 6.0.0 to 6.2.1 have a critical security issue (CVE-2026-103922 / GHSA-rvm3-566m-v7fv), fixed from 6.2.2 on. Capacitor Core and the Capacitor CLI move to 6.2.3 with it.
- **Build Tool Updates:** Updated some tools used only to build the app (xmldom, minimatch, brace-expansion). None of these are part of the installed app.

### 2. Included From v3.0.1
- **History Order After Restore:** History is ordered by when each image was made, so restored favourites are no longer out of order.
- **Smarter Duplicate Tags:** Tags in any number of brackets, and loose copies of tags inside a group, are now caught as duplicates.
- **Dock:** Android's swipe-up gesture no longer switches tabs, and the highlight no longer jumps when a finger lands.
- **Keyboard:** Closing the keyboard no longer drops the page back.

### 3. Updates
- **Older App Check:** If the v3.1 update reaches an app older than v3.1, Resolver asks to install the new APK instead of running without the security fix.

---

## Installation

Download the **v3.1 APK** from the releases page and install it over your current app. Your images and settings stay.
